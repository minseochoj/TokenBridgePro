# TokenBridgePro

TokenBridgePro enables decentralized, peer-to-peer transactions on a node-agnostic platform via multi-hop processing and real-time settlement.

TokenBridgePro is built to be simple and practical, focusing on doing one thing well.

**Why TokenBridgePro?**

- TokenBridgePro enables decentralized, peer-to-peer transactions
- on a node-agnostic platform via

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/TokenBridgePro.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure TokenBridgePro, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
